# エクストリーム花札：はじめて遊ぶ人へ

花札を知らなくても遊べる2人用の対戦ゲームです。まず同じ月の札を取ることだけ意識すれば大丈夫です。

1. 友達から届いたURLを開き、6文字の部屋IDを入力して参加します。
2. 「準備完了」を押します。2人そろったら作成者が開始します。
3. 手札から札を1枚出します。場に同じ月の札があれば取れます。
4. 手札の「取れる」マークは、場に同じ月がある印です。札にマウスを重ねると、その札で増える役と点数のヒントが見えます。
5. 役で1〜4点ならHPを回復、5点以上なら必殺が発動します。HPが100未満になると自動で覚醒します。HPを0にしたら勝ちです。

画面では、自分と相手の手札枚数、両者の取得札、HP、役、武将の特徴を確認できます。相手の手札の中身は非公開です。武将名の「特徴」を押すと、通常時と覚醒時の得意技が読めます。

詳しいガイドはプロジェクト内の `docs/友だち向け遊び方.md` を読んでください。
