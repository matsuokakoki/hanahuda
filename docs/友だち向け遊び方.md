# エクストリーム花札：はじめて遊ぶ人へ

これは2人で遊ぶ、花札と戦国武将の対戦ゲームです。花札を知らなくても大丈夫です。画面が「取れる札」と「役のヒント」を教えてくれます。

## はじめ方

1. 友達から届いたURLを開きます。
2. 画面で6文字の部屋IDを入力して「参加する」を押します。
3. 「準備完了」を押します。2人とも準備できたら、部屋を作った人が開始します。

## 画面の見かた

- **あなたの手札**: 自分だけが中身を見られます。手札の「取れる」マークは、場に同じ月の札がある印です。
- **場札**: ここに出ている札と、同じ月の札を手札から出すと取れます。
- **取得札**: 取った札です。自分と相手の取得札は、カードを押していつでも確認できます。
- **HP**: 0になると負けです。最初は300です。
- **役点**: 取った札で作れている組み合わせの点数です。
- **キャラクター特徴**: 武将名の横の「特徴」ボタンで確認できます。PCなら武将名にマウスを重ねても概要が出ます。

## 1ターンですること

1. 自分の手札を1枚押します。
2. 場に同じ月の札が1枚なら、2枚まとめて取れます。
3. 同じ月の札が2枚なら、どちらを取るか選びます。
4. 同じ月の札が3枚なら、場の3枚全部と出した札を取れます。
5. 場に同じ月がなければ、その札は場に置かれます。
6. その後、山札からも1枚めくられ、同じように取れるか判定されます。

## 役と点数のかんたんな考え方

役は「取った札の組み合わせ」です。役が新しくできた分だけ、そのターンの得点になります。手札にマウスを重ねると、今その札を取ったときにできる役のヒントが見えます。

- 1〜4点: 点数×10だけHPが回復します。
- 5点以上: 回復の代わりに武将の必殺技が出ます。HPが100未満になると武将は自動で覚醒します。
- 光札3枚の**三光**は5点、猪・鹿・蝶の**猪鹿蝶**は5点、赤い短冊3枚の**赤短**は5点です。
- 種札5枚、短冊5枚、カス札10枚でも1点から役になります。

細かい役を暗記する必要はありません。画面上の役点と「役ヒント」を見ながら、まずは同じ月を取ることを目指してください。

## 勝ち方・困ったとき

- 相手のHPを0にすると勝ちです。同時に0なら引き分けです。
- 手札と山札がなくなったら、HPが多い人の勝ちです。
- 相手の手札の中身は見えませんが、枚数と取得札は確認できます。
- 制限時間が0になったら「時間切れを申告」を押せます。
- 途中でやめるときは「投了する」を押します。
